# APC-Arbitrary-Precision-Calculator
## 📌 Description
A calculator designed to perform arithmetic operations on numbers larger than standard data types using linked list representation.

## 🚀 Features
- Handles very large numbers
- Supports addition, subtraction, multiplication
- Digit-by-digit computation
- Accurate carry and borrow handling

 ## 🛠️ Technologies Used
- C Programming
- Linked Lists
- Structures
- Pointers

## ⚙️ How It Works
- Stores numbers as linked lists
- Each node represents a digit
- Performs operations digit-by-digit
- Handles carry/borrow manually

## ⚠️ Challenges Faced
- Managing carry and borrow across nodes
- Handling different number lengths
- Efficient traversal of linked lists
- Avoiding memory leaks

## 💡 Key Learnings
- Implementation of big number arithmetic
- Advanced linked list operations
- Algorithm design for arithmetic logic

## ▶️ How to Run
-1 gcc *.c 
-2./apc
